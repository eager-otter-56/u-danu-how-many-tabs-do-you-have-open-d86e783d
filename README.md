# How Many Tabs Do You Have Open?

Entry for the make.fun bounty "How Many Tabs Do You Have Open?". The program
writes a single number — digits only, nothing else — to `entry.txt` in
`MAKEFUN_OUTPUT_DIR` (default `/output`): the honest count of browser tabs
open at the moment of entry.

Run it with:

```sh
python3 main.py
```
